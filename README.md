# Leaf Nest

Remember the source as you drink; return to nest as leaves fall.

May all thoughts, like fallen leaves, find their nest in SiYuan.

[中文](README_zh_CN.md)

---

Leaf Nest is a comprehensive plugin for [SiYuan](https://b3log.org/siyuan/?utm_source=ld246.com), developed and maintained by [𝓦𝓮𝓽𝓸𝓻𝓲𝓪](https://simplest-frontend.feishu.cn/docx/R1UxdUYPtoWVi2xapQXclJd2nUh#H5N9dK061o6R4sxUWTiccgvYnAc).

All thoughts, like fallen leaves, need a place to nest.

But nesting alone is not enough—thoughts also need to be put to use, helping us through output.

That is why Leaf Nest, starting as a utility plugin for SiYuan, set its goal to—**Make input and output easier.**

See the full guide: [Leaf Nest — Make input and output easier](https://simplest-frontend.feishu.cn/docx/B3NndXHi7oLLXJxnxQmcczRsnse).

A new Leaf Nest is on the way—stay tuned; the documentation will be updated in sync.
